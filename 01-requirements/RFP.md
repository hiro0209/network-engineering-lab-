# RFP — New Adelaide Office Network Infrastructure Project

**RFP Reference:** ABC-NET-2026-001
**Client:** ABC Pty Ltd
**Location:** Adelaide, South Australia
**Project Type:** New Office Network Deployment

---

## 1. Company Background

ABC Pty Ltd is a growing professional services company establishing a new office in Adelaide.

The company requires a new network infrastructure to support its business operations. The new office will initially accommodate approximately 30 employees.

The network should support current business requirements while allowing the organisation to expand in the future.

---

## 2. Project Objectives

The primary objectives of this project are to provide:

* Reliable Internet connectivity
* Wired network connectivity
* Secure wireless connectivity for employees
* Guest wireless Internet access
* Secure access to internal company resources
* Secure remote access for authorised employees
* Protection of internal network resources
* Appropriate network management capabilities
* A network architecture that can support future growth

---

## 3. Office Environment

The new office is currently being prepared.

No network infrastructure has been deployed at the site yet.

The office will include:

* Employee work areas
* Areas for IT/network equipment
* Areas requiring wired network connectivity
* Areas requiring wireless coverage

The supplier is expected to consider both the physical and logical network requirements when developing the proposed solution.

---

## 4. Users

The office will initially have approximately 30 employees.

IT administrators will be responsible for managing the network infrastructure.

Visitors and temporary users may also require network access.

---

## 5. Network Connectivity

The new office will require:

* Wired network connectivity
* Employee Wi-Fi
* Guest Wi-Fi
* Internet connectivity

Employees will require access to the network resources and Internet services necessary for normal business activities.

The proposed solution should provide appropriate network performance and reliability for business operations.

---

## 6. Internal Resources

The organisation uses a combination of internal IT resources and cloud-based services.

Internal resources may include:

* File resources
* Network printers
* Internal applications
* Other corporate resources

The network should provide appropriate controls to protect internal resources from unauthorised access.

---

## 7. Remote Access

Some employees work outside the office.

The solution must provide secure remote access for authorised users.

Remote users should receive only the level of network access required for their business activities.

---

## 8. Guest Network

Visitors and temporary users may require Internet access.

Guest users should be able to access the Internet without being able to access the company's internal network resources.

The proposed solution should provide appropriate isolation between guest and corporate network traffic.

---

## 9. Network Security

Security is an important requirement of this project.

The proposed network should consider appropriate security controls, including:

* Network segmentation
* Firewall protection
* Access control
* Wireless security
* Remote access security
* Administrative access controls
* Monitoring and logging

The solution should follow generally accepted enterprise network security practices.

---

## 10. Availability and Reliability

The network will be important to daily business operations.

The proposed solution should consider:

* Equipment failures
* Internet connectivity failures
* Configuration failures
* Recovery procedures
* Significant single points of failure
* Appropriate availability and resilience measures

The supplier should identify significant availability risks and provide recommendations where appropriate.

---

## 11. Scalability

The network should support future organisational growth.

The solution should consider potential increases in:

* Employees
* Network-connected devices
* Wireless users
* Internet traffic
* IT services

The organisation does not want to perform a complete network redesign whenever the business grows.

---

## 12. Network Management

IT administrators will need appropriate capabilities to:

* Monitor network infrastructure
* Troubleshoot network problems
* Manage network devices
* Review relevant logs
* Identify network failures
* Perform routine administrative tasks

The proposed solution should provide appropriate management and monitoring capabilities.

---

## 13. Documentation

The supplier is expected to provide technical documentation covering, where applicable:

* Network topology
* IP addressing
* Network segmentation
* Device configuration
* Security configuration
* Operational procedures

Documentation should be suitable for use by the client's IT administrators.

---

## 14. Expected Deliverables

The supplier is expected to provide the following deliverables:

1. Requirements analysis
2. Network architecture
3. Network design
4. Equipment recommendations
5. IP addressing plan
6. Security design
7. Implementation plan
8. Testing plan
9. Network implementation
10. Technical documentation
11. Operational handover

---

## 15. Project Constraints

The following constraints should be considered:

* The office must be operational by the agreed project completion date.
* Network deployment should minimise disruption to business operations.
* The solution should be maintainable by the client's IT administrators.
* The network should support future expansion.
* Technologies should have appropriate commercial/vendor support.

---

## 16. Supplier Response

Before developing the final network design, the supplier is expected to identify any additional information required from ABC Pty Ltd.

The client expects the supplier to raise questions where requirements are:

* Unclear
* Incomplete
* Conflicting
* Not yet determined

The supplier should not make significant assumptions without identifying them to the client.
